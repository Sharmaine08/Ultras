
# Focus Timer App

A simple timer application built with React Native and Expo for our BSIT school project.

## Project Description

Focus Timer helps users set a duration for activities such as studying, taking breaks, and exercising. Users can start, pause, resume, and reset their timer.

## Features

- Select hours, minutes, and seconds.
- Choose a timer mode: Study, Break, or Exercise.
- View the countdown using a circular timer display.
- Pause and resume the timer.
- Delete the current timer and return to the setup screen.
- View recent timer records and session information.
- Display the current time.

## Technologies Used

- React Native
- Expo
- TypeScript
- React Hooks (`useState`, `useEffect`)
- React Native SVG

## Requirements

- Node.js and npm
- Expo-compatible development environment
- Expo Go or another supported way to run the app

## Installation

1. Clone the repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Follow the terminal instructions to run the application.

## Project Structure

- `src/app/` — Application screens.
- `src/components/TimePicker.tsx` — Time selection component.
- `src/components/TimerCircle.tsx` — Circular timer display.
- `src/components/TimerControls.tsx` — Timer action buttons.
- `src/components/TimerHistory.tsx` — Recent timer records.
